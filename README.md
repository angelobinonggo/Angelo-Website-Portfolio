# Angelo Binonggo - Personal Portfolio Website

Welcome to the repository for my personal portfolio website! I am **Angelo Binonggo**, a passionate Web Designer & Developer based in the Philippines. This website showcases my projects, skills, services, and my professional background.

## Features

- **Responsive Design:** Fully responsive layout that adapts to all screen sizes (mobile, tablet, desktop).
- **Dark/Light Mode Theme:** Interactive theme toggle for better user accessibility and preference.
- **Dynamic UI/UX:** Smooth scrolling, micro-animations, and scroll-reveal effects to provide a premium user experience.
- **Portfolio Showcase:** Includes a detailed modal-based view of my creative works in web development, design, and student leadership.
- **Resume Section:** Neatly organized tabs highlighting my education, experience, and technical skills.

## Built With

- **HTML5:** Semantic and accessible structure.
- **CSS3:** Custom styling and responsive layouts (no external framework, custom tokens).
- **JavaScript (Vanilla):** Logic for the theme toggle, responsive navigation, scroll indicators, modals, and dynamic interactions.
- **Remix Icon:** Open-source icon library.
- **ScrollReveal JS:** For scroll animations.
- **Swiper JS:** For content sliders.

## Project Structure

## Running the Project Locally

To view the website on your local machine:
1. Clone this repository to your local computer.
2. Navigate to the project directory.
3. Open `index.html` in your preferred web browser. Alternatively, you can use a local development server like VS Code's "Live Server" extension for a better experience.
